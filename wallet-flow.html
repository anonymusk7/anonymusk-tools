How it works & limits. Data: Blockscout public API (v2 address transactions and token transfers, latest ~100 of each per wallet, plus Blockscout's address tags for exchange/protocol names). USD uses Blockscout's current token and coin prices, not the price at transfer time, so old flows are approximate. Tokens without a price count as $0. Internal transactions (contract-made ETH sends) are not included. Green = into the traced wallet(s), red = out. Labels are Blockscout's, not ours. Throttled to about 4 requests/s with back-off on HTTP 429.

Not financial advice. A transfer is not proof of who controls an address. Verify on a block explorer.
