How it works & limits. Holders and labels: Blockscout public API (v2 holders; tags show exchanges). Links: (A) this token's transfers between top holders in the most recent 200k blocks (about 4 weeks on Ethereum, a few days on Base/Optimism, under a day on Arbitrum), read from Transfer logs via free public RPCs (Flashbots, PublicNode, chain-operator endpoints). Public RPCs often refuse or time out on log queries, so the window actually scanned is printed under the map and can be shorter, or empty; (B) each holder's first incoming native transfer ("first funder"). A funder shared by 2+ holders becomes a dotted bubble. If that funder is a labelled exchange, holders are only linked when funded in the same 10-minute window, because thousands of strangers withdraw from the same exchange. This is a transparent approximation: we don't see cross-token or cross-chain links, and a link is not proof of common ownership. Results are cached in your browser for 6 hours. Blockscout limits free use (we throttle to about 4 requests/s and back off on HTTP 429). A 100-holder map takes roughly 30–60 seconds the first time.

Not financial advice. On-chain links are hints, not proof. Verify on a block explorer.
